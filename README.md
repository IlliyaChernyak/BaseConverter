# 🔢 Number Base Converter
A lightweight, offline web app for instant conversions between **Decimal**, **Hexadecimal**, **Binary**, and **Octal** number systems.

## ✨ Features
- **4-way conversion** — Decimal ↔ Hex ↔ Binary ↔ Octal
- **Type anywhere** — Enter a number in any field and convert from there
- **Input validation** — Instant error feedback for invalid characters
- **Keyboard friendly** — Press `Enter` to convert without clicking
- **Zero dependencies** — Single HTML file, no frameworks, no build step
- **Fully offline** — Runs locally in any modern browser
## 🚀 Getting Started
1. **Clone or download** this repository:
   ```bash
   git clone https://github.com/illiyachernyak/calc.git
   ```
2. **Open** `converter.html` in your browser (double-click the file).
That's it — no server, no install, no setup.
## 🖥️ Usage
1. Type a number into any of the four input fields:
   | Field       | Accepted Characters |
   |-------------|---------------------|
   | **Decimal** | `0-9`               |
   | **Hex**     | `0-9`, `A-F`        |
   | **Binary**  | `0`, `1`            |
   | **Octal**   | `0-7`               |
2. Click **Convert** or press **Enter**.
3. All other fields auto-fill with the correct conversion.
4. Click **Clear** to reset everything.
